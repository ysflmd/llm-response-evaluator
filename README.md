# LLM Response Evaluator

A small Python project for evaluating responses generated by large language models.

## Purpose

The goal of this project is to test LLM responses across a structured set of prompts and evaluate them based on:

- Relevance
- Completeness
- Consistency
- Instruction following

The results are stored in CSV format and analyzed using Pandas.

## Technologies

- Python
- Pandas
- CSV

## Project Structure

- `prompts.csv` - Contains the test prompts
- `evaluator.py` - Runs the evaluation workflow
- `results.csv` - Stores the evaluation results

## Current Status

This project is currently being developed. The next step is to connect the evaluator to an LLM API so responses can be generated automatically.

## Future Improvements

- Connect to an LLM API
- Compare multiple models
- Add automated scoring
- Analyze common failure patterns
